# API Reference

CRM AI Assistant exposes a JSON HTTP API for document indexing and grounded question answering. The local API base URL is `http://localhost:8080`.

On Windows, start the service from the repository root with `.\run.ps1` after configuring `.env` and starting Docker Desktop. Keep the service terminal open. A non-empty `OPENAI_API_KEY` must be configured for application startup. Document creation, reindexing, and question answering use that key to generate embeddings or answers. Health checks and document reads do not make OpenAI requests; document reads require the local service and database.

To exercise document creation, embedding, retrieval, and a sourced answer, run `.\scripts\smoke-test.ps1` in another PowerShell terminal while the API is running. The script creates a uniquely titled sample document and checks that `/ask` returns it as a source.

## `GET /health`

Check that the HTTP server is responding.

### Example

```powershell
Invoke-RestMethod http://localhost:8080/health
```

```bash
curl -i http://localhost:8080/health
```

### Success response

`200 OK`, plain text:

```text
ok
```

## `POST /documents`

Create a document. The service stores the document and splits its content into chunks in the same database transaction. Chunk text is not included in the API response.

### Request

Content type: `application/json`

| Field | Type | Required by current handler | Description |
| --- | --- | --- | --- |
| `title` | string | Yes | Document title. |
| `content` | string | Yes | Full document text to store and split into chunks. |

The handler checks that the body is valid JSON and both fields are non-empty. Creating the document also sends its chunks to OpenAI for embedding. This requires a valid `OPENAI_API_KEY` in `.env`; a failed embedding request means the document and its chunks are not written.

### PowerShell example

```powershell
$body = @{
    title = "Customer onboarding guide"
    content = "This document explains the onboarding process for new clients."
} | ConvertTo-Json

Invoke-RestMethod `
    -Method Post `
    -Uri http://localhost:8080/documents `
    -ContentType "application/json" `
    -Body $body
```

### curl example

```bash
curl -i -X POST http://localhost:8080/documents \
  -H "Content-Type: application/json" \
  -d '{"title":"Customer onboarding guide","content":"This document explains the onboarding process for new clients."}'
```

### Success response

`201 Created`, JSON:

```json
{
  "message": "Document created successfully",
  "id": 1
}
```

The ID is generated by PostgreSQL and will differ from the example.

### Errors

- `400 Bad Request` with plain-text `Invalid request body` if the request body is not valid JSON or cannot be read.
- `500 Internal Server Error` with plain-text `Failed to create document` if OpenAI embedding generation or database persistence fails.

## `POST /documents/{id}/reindex`

Re-split a previously saved document using the current chunk size and overlap, generate embeddings, and replace its stored chunks atomically. Use this for documents that were created before chunk embeddings were added, or after changing the chunk settings.

### Example

```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8080/documents/3/reindex
```

### Success response

`200 OK`, JSON:

```json
{
  "document_id": 3,
  "chunks_indexed": 5
}
```

### Errors

- `400 Bad Request` if the ID is not a positive integer.
- `404 Not Found` if there is no document with that ID.
- `500 Internal Server Error` if embedding or storage fails. On failure, the old chunks remain intact.

## `GET /documents`

List all documents, newest ID first. The current endpoint does not support pagination or filtering.

### Examples

```powershell
Invoke-RestMethod http://localhost:8080/documents
```

```bash
curl -i http://localhost:8080/documents
```

### Success response

`200 OK`, JSON:

```json
{
  "documents": [
    {
      "id": 1,
      "title": "Customer onboarding guide",
      "content": "This document explains the onboarding process for new clients."
    }
  ]
}
```

When there are no documents, `documents` is an empty array.

### Error

- `500 Internal Server Error` with plain-text `Failed to list documents` if the database query fails.

## `GET /documents/{id}`

Fetch one document by its numeric database ID.

### Examples

```powershell
$id = 1
Invoke-RestMethod "http://localhost:8080/documents/$id"
```

```bash
curl -i http://localhost:8080/documents/1
```

### Success response

`200 OK`, JSON:

```json
{
  "document": {
    "id": 1,
    "title": "Customer onboarding guide",
    "content": "This document explains the onboarding process for new clients."
  }
}
```

### Errors

- `400 Bad Request` if the ID is not a positive integer.
- `404 Not Found` with plain-text `Document not found` if no document has that ID.
- `500 Internal Server Error` with plain-text `Failed to get document` if the database lookup fails for another reason.

## `POST /ask`

Ask a question using the most similar stored document chunks. The API embeds the question, retrieves up to five chunks by cosine similarity, and asks the configured OpenAI Responses API model to answer from those sources. Source document titles, chunk indexes, and similarity scores are returned so you can inspect the retrieval results.

### Request

```json
{
  "question": "How soon should a new lead receive an initial contact attempt?"
}
```

### PowerShell example

```powershell
$body = @{ question = "How soon should a new lead receive an initial contact attempt?" } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://localhost:8080/ask -ContentType "application/json" -Body $body
```

### curl example

```bash
curl -i -X POST http://localhost:8080/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"How soon should a new lead receive an initial contact attempt?"}'
```

### Success response

`200 OK`, JSON:

```json
{
  "answer": "The sales representative should make an initial contact attempt within one business day.",
  "sources": [
    {
      "document_id": 1,
      "title": "Northstar CRM Customer Support and Sales Guide",
      "chunk_index": 0,
      "content": "Lead Qualification ...",
      "similarity": 0.82
    }
  ]
}
```

Similarity values are returned for inspection; the MVP does not apply a minimum-score threshold. If there are no chunks with stored embeddings, the API returns a helpful answer and an empty `sources` list without calling the text generation model.

### Errors

- `400 Bad Request` if the request JSON is invalid or `question` is empty.
- `502 Bad Gateway` if an OpenAI embedding or answer request fails.
- `500 Internal Server Error` if PostgreSQL cannot search the stored chunks.

## Chunking configuration

The API creates chunks when a document is created. Configure these values in `.env` before starting the service:

```env
DOCUMENT_CHUNK_SIZE=1000
DOCUMENT_CHUNK_OVERLAP=150
```

Chunk size and overlap are measured in Unicode code points by the current splitter. Overlap must be at least `0` and less than the chunk size. Invalid chunking settings cause the splitter to return no chunks; the document itself can still be created. Wrapped lines inside a paragraph are reflowed to spaces, while blank lines between paragraphs are preserved inside chunks. Each chunk is embedded with OpenAI's `text-embedding-3-small` model (1,536 values) and stored in PostgreSQL using pgvector. `OPENAI_CHAT_MODEL` chooses the model used by `POST /ask` and defaults to `gpt-6-luna`.

To inspect stored chunks in the local PostgreSQL container:

```powershell
docker exec crm-ai-postgres psql -U postgres -d crm_ai_assistant -c "SELECT document_id, chunk_index, content FROM document_chunks ORDER BY document_id, chunk_index;"
```
